## 詳しい説明（4000文字以内）

```
「商談前のひと言、何を話そう…」をなくす、ルート営業のための雑談アシスタントです。

取引先の業界・年代・役職を選ぶだけで、いま話題のニュースをきっかけにした自然な雑談ネタを、すぐに3つ用意します。各ネタは、そのまま口に出せる「3ステップ公式」で構成されています。

■ 3ステップ公式
1. ニュース・話題のふり … 最近の時事や業界トレンドを軽く切り出す
2. 主観・共感 … 押し付けない、ひと言の感想や共感
3. 質問 … 相手が答えやすい、会話が広がるオープンな質問

さらに、会話を深める「豆知識」や、元ネタを確認できる検索キーワードも付くので、自信を持って話し始められます。

■ こんな方に
・ルート営業／渉外で、毎日いろいろな取引先を回る方
・商談前のアイスブレイクが苦手な方
・若手で、年上の担当者との会話に困っている方
・定番の天気の話から一歩抜け出したい方

■ 主な機能
・相手の業界・年代・役職に合わせた雑談ネタを3件生成
・3ステップ公式＋豆知識＋元ネタ検索ワード
・気に入ったネタのストック（保存）と履歴
・顧客メモ（取引先ごとのメモ）に合わせた雑談
・音声読み上げ（プレミアム）
・データは端末内に保存。アカウント登録・ログイン不要

■ プライバシー
顧客メモや設定などの情報は、お使いの端末内にのみ保存されます。雑談生成のときだけ、選んだ業界・年代などの必要な情報がAIに送信されます。詳しくはプライバシーポリシーをご覧ください。

※ 政治・宗教などセンシティブな話題は避ける設計です。最新ニュースの固有名詞は断定しないトーンで提案します。
```

## データセーフティ（Data safety）回答の指針

Play Console の「データセーフティ」フォームでは、おおむね以下の方針で回答できます
（最終的な回答はご自身の運用に合わせて確認してください）。

- **データ収集**：アプリは個人情報をサーバーに収集・保存しません（端末内保存）。
- **データ共有**：雑談生成のため、入力テキスト（業界・年代・任意の顧客メモ）をAIサービス提供者へ送信します。
  - 目的：アプリの機能（コンテンツ生成）
  - 永続保存：なし（生成処理のためのみ）
- **暗号化**：通信は HTTPS で暗号化。
- **データ削除**：アプリ内またはアンインストールで端末内データを削除可能。
- **広告／トラッキング**：なし。

> 「ユーザーが入力したテキスト」を扱う旨は正直に申告するのが安全です（App content → Data safety）。
